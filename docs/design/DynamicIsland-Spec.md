# PonyClean 灵动岛（Dynamic Island）设计规约 v1.0

**文档**: `docs/design/DynamicIsland-Spec.md`
**版本**: 1.0
**状态**: ✅ 已实现（2026-07-01）
**关联**: ARCHITECTURE.md, Window-Morph-Spec.md

---

## 1. 概述

将 PonyClean 窗口形态从「全窗口 ↔ 胶囊吸附」重构为**灵动岛（Dynamic Island）**样式：

| 特性 | 描述 |
|---|---|
| **锚点** | 屏幕顶部正中央，胶囊形态为常驻 handle |
| **水平拖拽** | 胶囊可在水平方向自由拖动，停留在用户放置位置 |
| **窗口形态** | 仿 Apple 灵动岛：胶囊 + 可滑出面板，一体式 pill 造型 |
| **动画** | 基于物理的弹簧阻尼（spring + bounce），质感丝滑 |
| **布局** | **图标在左侧，详情在右侧** |

## 2. 窗口规格

### 2.1 物理窗口（不变）

| 属性 | 值 |
|---|---|
| 尺寸 | `315 × 100` — **固定，等于岛高度** |
| 装饰 | `decorations: false` |
| 可缩放 | `resizable: false` |
| 透明 | `transparent: true` |
| 置顶 | `alwaysOnTop: true` |
| 任务栏 | `skipTaskbar: true` |
| 定位 | 屏幕顶部正中央（水平居中，`Y = 0`） |

### 2.2 视觉组成

```
┌──────────────────────────────────┐
│  ┌──────────────────────────┐   │  ← Capsule handle (160×40)
│  │  45 CPU   │   78 MEM      │   │     常驻顶部，始终可见
│  └──────────────────────────┘   │
├──────────────────────────────────┤
│ ┌──────┬───────────────────────┐│  ← Dynamic Island 面板
│ │ 🖥   │  [内容面板]           ││     （spring 动画滑入/滑出）
│ │ 🗑   │   MonitorPanel /      ││
│ │      │   CleanerPanel        ││
│ │      │                       ││
│ │ ❌   │                       ││
│ └──────┴───────────────────────┘│
└──────────────────────────────────┘
     ↕ 整体以 spring 物理动画从顶部滑入/滑出
```

### 2.3 样式规范

| 属性 | 值 |
|---|---|
| 背景 | 毛玻璃效果 `backdrop-filter: blur(24px) saturate(180%)` |
| 底色 | `hsl(30 12% 9% / 0.85)` 半透明深色 |
| 圆角 | `16px`（面板整体 pill 形状） |
| 边框 | `1px solid hsla(0,0%,100%,0.08)` + 顶部高光线 `hsla(0,0%,100%,0.12)` |
| 阴影 | `0 8px 32px rgba(0,0,0,0.5)` 大阴影营造悬浮感 |
| transform-origin | `top center` — 以顶部中央为轴 |

## 3. 状态机

### 3.1 状态定义

| 状态 | 含义 | 面板可见性 |
|---|---|---|
| `idle` | 空闲态 | 面板隐藏（translateY = -面板高度） |
| `entering` | 滑入中 | spring 动画进行中 |
| `visible` | 可见态 | 面板全显示（translateY = 0） |
| `leaving` | 滑出中 | spring 动画进行中 |

### 3.2 状态转换

```
[idle] ──(click 胶囊)──► [entering] ──(spring 动画结束)──► [visible]
  ▲                                                              │
  │                                                              │ (mouseleave 面板 + 5s 空闲)
  │                                                              ▼
  └────────────────────── [leaving] ◄─────────────────────────────┘
                              │
                              └──(spring 动画结束)──► [idle]
```

### 3.3 触发规则

| 动作 | 触发 | 备注 |
|---|---|---|
| 鼠标进入胶囊 | 仅更新 hover 视觉态 | 不展开面板，避免阻碍拖拽 |
| 鼠标离开面板 | 启动 5s 空闲计时器 | 鼠标再进入则重置计时器 |
| 5s 空闲超时 | `visible` → `leaving` | spring 滑出，带会弹动效 |
| 单击胶囊 | `idle` → `entering` | 明确展开意图 |
| 水平拖拽胶囊 | 任意态 | 实时移动窗口 X 坐标 |
| 扫描/清理任务进行中 | 暂停空闲计时器 | 面板保持可见 |

## 4. 动画规范

### 4.1 物理参数

使用 `motion-v` 的 spring 物理引擎：

| 动画 | stiffness | damping | mass | 效果 |
|---|---|---|---|---|
| **滑入**（entering） | `250` | `20` | `0.8` | 平滑、轻微过冲后稳定 |
| **滑出**（leaving） | `180` | `12` | `1.0` | 更明显的弹性回弹，「会弹」动效 |

### 4.2 动画曲线参考

```
滑入位移: y: -面板高度 → 0     (spring, stiffness: 250, damping: 20, mass: 0.8)
滑出位移: y: 0 → -面板高度      (spring, stiffness: 180, damping: 12, mass: 1.0)
不透明度: 0 → 1 / 1 → 0         (同步于位移，300ms ease)
```

### 4.3 典型 bounce 表现

```
滑出时（leaving）:
  t=0ms   → y = 0         （开始）
  t=100ms → y = -200px    （快速上滑）
  t=250ms → y = -320px    （过冲，超过目标）
  t=350ms → y = -280px    （回弹）
  t=450ms → y = -300px    （稳定在目标位置）

滑入时（entering）:
  t=0ms   → y = -面板高度  （开始）
  t=150ms → y = 20px      （过冲，稍低于目标）
  t=250ms → y = -5px      （回弹）
  t=350ms → y = 0         （稳定）
```

> 以上为示意值，实际表现由物理引擎实时计算，非预设关键帧。

## 5. 胶囊拖拽

### 5.1 行为规范

| 行为 | 规则 |
|---|---|
| 拖拽触发 | `mousedown` 在胶囊区域 |
| 拖拽优先级 | 移动超过阈值后判定为拖拽，不触发点击展开 |
| 拖拽范围 | 水平方向，限制在当前显示器左右边界内 |
| 释放位置 | **保留用户在释放时的水平位置**，不 snap-back |
| 窗口 Y | 始终保持 `Y = 0`（屏幕顶部） |
| 边界约束 | `EDGE_PADDING ≤ targetX ≤ monitorWidth - CAPSULE_W - EDGE_PADDING` |

### 5.2 实现要点

- 使用 `requestAnimationFrame` 驱动，避免频繁 IPC
- 每个 mousemove 事件记录 pendingX，在 rAF 中批量应用
- 拖拽过程中不触发展开或 idle 计时器
- 拖拽结束后重新启动空闲检测

## 6. 布局规范

### 6.1 左侧图标列（36px）

| 图标 | 功能 | 快捷键 |
|---|---|---|
| `Activity` | 切换到进程监控面板 | — |
| `HardDrive` | 切换到 C盘清理面板 | — |
| `X` | 退出应用 | — |

- 图标垂直居中排列，间距 `12px`
- 每个图标 `24×24`，hover 时高亮
- 激活态使用 `text-primary` 金色高亮

### 6.2 右侧内容区（~265px）

- 继承现有 MonitorPanel / CleanerPanel 内容
- 宽度适配：从原本 315px → 约 265px
- 顶部紧凑标题行（仅文字标识当前面板名称）

### 6.3 胶囊 handle

- 尺寸：`160 × 40`，圆角 `9999px`
- 完全居中于窗口顶部
- CPU 在左半区，MEM 在右半区，中间 `1px` 分隔线
- 可视化 hover 暗示：轻微缩放或发光

## 8. 验收标准

| # | 验收条件 |
|---|---|
| 1 | 胶囊始终固定在屏幕顶部正中央 |
| 2 | 水平拖拽胶囊后停留在用户放置位置，不 snap-back |
| 3 | 拖拽释放后胶囊中心不自动回弹到屏幕中心 |
| 4 | 鼠标进入胶囊只出现轻量 hover 反馈，不展开面板 |
| 5 | 面板完全滑入后可在水平方向拖拽胶囊 |
| 6 | 单击胶囊 → 面板从顶部平滑滑入（spring 动画） |
| 7 | 鼠标离开面板 5s 后 → 面板从顶部弹性滑出（带 bounce） |
| 8 | 滑出动画有明显「会弹」动效（overshoot + 回弹） |
| 9 | 滑入/滑出动画基于物理弹簧（非 ease 曲线） |
| 10 | 扫描/清理任务进行中面板保持可见 |
| 11 | 左侧图标列显示 Activity、HardDrive、X 三个图标 |
| 12 | 右侧内容区正常显示监控面板/C盘清理面板 |
| 13 | 面板背景为毛玻璃效果（`backdrop-filter: blur`） |
| 14 | 面板整体使用 pill 形状的 `border-radius: 16px` |
| 15 | 胶囊 hover 有视觉反馈（轻微放大或 glow） |

---

## 9. 不在此范围内

- 胶囊位置偏好持久化（未来版本）
- 多显示器适配（首版仅当前窗口所在显示器）
- 面板缩放/尺寸调整
- 拖拽到屏幕边缘自动吸附
- 自定义动画参数配置
